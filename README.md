# SlopiFY 🎵

SlopiFY is a modern, minimalist music streaming and uploading application. 

## Features
- **User Authentication:** Sleek, glassmorphism-inspired login interface.
- **Music Library:** Browse and stream your favorite tracks with a live search functionality and a centered search bar.
- **Upload:** Upload your own audio files directly to the platform.
- **Modern UI:** Built with a dark, slate/charcoal design system for a premium feel.

## Tech Stack
- React
- Vite
- Custom CSS (Design Tokens & Glassmorphism)

## Getting Started

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Run the Development Server:**
   ```bash
   npm run dev
   ```

3. **Build for Production:**
   ```bash
   npm run build
   ```
